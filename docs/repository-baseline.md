# What this baseline contains

This initial `story-check-ai` repository contains **documentation and configuration only**.

Included: README with Mermaid diagrams, Apache-2.0 LICENSE, copied maintainer support image, AGENTS.md, one optional Codex agent, two technology-specific skills, story/release documentation, architecture/API/model/test plans, `.env.example`, and `.gitignore`.

Not included: `pom.xml`, `src/`, runnable Spring Boot classes, frontend HTML/CSS/JS, Dockerfile, Compose YAML, GitHub Actions workflow, lock files, pre-built screenshots, tests, or fake verification output. Those belong to the approved stories STC-001–004.

This distinction is intentional: publication of the baseline alone must not be described as implementation of the application.
